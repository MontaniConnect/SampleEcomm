Prototype limits

  • Search, filters, quantity changes and totals are static. The only script is assets/motion.js (scroll reveals).
  • Forms submit with GET to the next page so you can walk the flow. Nothing is stored.
  • Currency is shown as XXX because the launch currency is not confirmed.
  • Motion is subtle (200 to 400ms): hero entrance, scroll reveals, hover effects. All of it is off when the visitor prefers reduced motion.
